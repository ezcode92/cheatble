# Cheatble

[English](README.md) · [한국어](README.ko.md)

**버전 1.0.1** — 작업 화면 옆에 띄워 두는 무료 macOS 단축키 시트입니다. 현재 앱을 자동으로 따라가거나 macOS 기본 단축키와 저장된 앱 목록을 선택해 볼 수 있습니다. 서버·계정·구독·외부 패키지 없이 로컬에서 동작합니다.

**macOS 13 이상**에서 사용할 수 있습니다. 현재 앱 화면과 기본 단축키 설명은 한국어입니다.

## 설치

1. 아래 [소스 빌드 방법](#소스-빌드)을 따라 빌드하거나, 사용 중인 Mac의 CPU에 맞는 빌드 파일을 준비합니다.
2. `dist/Cheatble.app`을 `/Applications`(응용 프로그램)로 옮겨 실행합니다.
3. 메뉴 막대의 **⌘ 아이콘**에서 시트 표시·숨기기, 설정, 종료를 선택합니다. 응용 프로그램 폴더에서 Dock으로 끌어 놓아 고정할 수도 있습니다. Dock 아이콘을 누르면 시트가 나타납니다.
4. 실제 앱 메뉴까지 읽으려면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Cheatble을 허용합니다. 앱의 **권한 설정** 버튼으로 해당 화면을 열 수 있습니다.

내장 단축키, 저장된 목록, 시트 전역 단축키는 손쉬운 사용 권한 없이도 동작합니다. 권한은 다른 앱의 메뉴를 읽고 활성 창이 있는 모니터를 따라갈 때 필요하며 변경 상태는 자동 확인합니다.

로컬 빌드는 빌드한 Mac에서 생성한 인증서로 서명합니다. Apple 공증을 받은 공개 배포용 빌드는 아닙니다. 설치본을 업데이트할 때는 같은 서명 키를 사용하세요.

## 사용법

### 단축키 목록 전환

| 상단 선택 영역 | 동작 |
| --- | --- |
| 현재 앱 아이콘 | 활성 앱이 바뀔 때마다 해당 앱의 단축키를 자동 표시합니다. |
| 사과 아이콘 | macOS 기본 단축키를 표시합니다. |
| 저장된 앱 아이콘과 드롭다운 | 검색 가능한 앱 아이콘 목록을 엽니다. 선택한 목록을 계속 유지합니다. |

macOS나 저장된 앱을 선택한 상태에서 다른 앱으로 전환하면 현재 앱 아이콘만 바뀌고 목록·검색·필터는 유지됩니다. 현재 활성 앱은 첫 번째 선택 영역에 있으므로 드롭다운에 중복 표시하지 않습니다.

드롭다운에서 앱 이름을 입력해 검색하거나 **방향키**로 이동한 뒤 **Return**으로 선택하세요. **Escape** 또는 선택창 단축키를 다시 누르면 닫힙니다. 실제 메뉴를 읽은 앱은 자동 저장되어 해당 앱을 종료한 뒤에도 선택할 수 있습니다.

### 기본 전역 단축키

| 동작 | 단축키 |
| --- | --- |
| 시트 표시·숨기기 | `Control + Option + Command + Return` |
| 현재 앱 따라가기 | `Control + Option + Command + J` |
| macOS 목록 표시 | `Control + Option + Command + K` |
| 저장된 앱 선택창 열기·닫기 | `Control + Option + Command + ;` |

왼손으로 보조 키를, 오른손으로 마지막 키를 누르면 됩니다. 설정에서 각 조합을 변경하거나 끌 수 있습니다. 알려진 목록과 시스템 등록 상태로 충돌을 검사하지만 모든 앱의 내부 단축키를 확인할 수는 없습니다.

새로 읽은 팩과 설정한 전역 단축키가 겹치면 해당 키의 등록을 잠시 해제하고 설정에 충돌을 표시합니다. 충돌하는 팩을 제거하면 저장한 키 조합을 바꾸지 않고 다시 등록합니다.

### 위치·크기·투명도 조절

- 상단 **CHEATBLE 영역**을 드래그하면 위치를 옮길 수 있으며 변경한 위치는 저장됩니다.
- **왼쪽 아래 사선 손잡이**는 너비와 높이, 왼쪽 가장자리는 너비, 아래쪽 가장자리는 높이를 조절합니다. 설정의 슬라이더도 사용할 수 있습니다.
- 최소 너비는 **240pt**이며, 너비 **596pt부터 2단**, **888pt부터 3단**으로 표시합니다.
- 하단 불투명도 슬라이더는 배경·글자·아이콘을 함께 **20~100%**로 조절합니다.
- 설정의 **자동 오른쪽 배치로 되돌리기**를 누르면 활성 창이 있는 모니터의 오른쪽을 따라갑니다.

### 검색과 개인 설정

- 동작 이름, 키 조합, 설명, 별칭, 메뉴 경로로 검색합니다. 보조 키 필터(`⌘`, `⌥`, `⌃`, `⇧`)는 선택한 키를 모두 포함하는 조합을 보여 줍니다. 별 필터는 즐겨찾기를, 체크 필터는 평소 숨겨지는 공부 완료 항목까지 보여 줍니다.
- 카테고리 헤더를 누르면 펼치거나 접습니다. 단축키 행을 누르면 설명과 **즐겨찾기**, **공부 완료**, **연필·수정** 버튼이 나타납니다.
- **설정 → 앱별 단축키 설정**에서 항목을 추가·수정·제거하세요. 직접 수정한 값을 제거하면 원래 메뉴 또는 기본값이 다시 나타납니다. Cheatble의 표시 내용을 수정하는 것이며 대상 앱의 실제 단축키 설정을 변경하지는 않습니다.
- 설정의 JSON 가져오기·내보내기로 사용자 항목, 저장한 메뉴, 즐겨찾기, 공부 완료, 접힌 그룹을 백업합니다. 가져오기는 합치기이며 같은 동작의 사용자 값은 가져온 값이 우선합니다. 추가 단축키 팩은 별도 파일입니다.
- 설정의 **메뉴 더 읽기**는 대상 앱으로 전환한 뒤 메뉴를 잠시 열어 늦게 생성되는 항목을 읽습니다. 일반 갱신은 메뉴를 열거나 명령을 실행하지 않습니다.

기호: `⌘` Command · `⌥` Option · `⌃` Control · `⇧` Shift · `⇥` Tab · `↩` Return · `⌫` Delete. 한 묶음 안의 키는 함께 누릅니다. `Control+B → C`는 앞의 조합을 누르고 놓은 다음 C를 누릅니다. 편집할 때 방향키는 `Left`, `Right`, `Up`, `Down`, 더하기 키는 `Plus`로 입력하세요.

## 새로운 앱 단축키 추가

### 에이전트에게 팩 생성 요청하기

1. 추가하려는 앱을 활성화하고 Cheatble의 현재 앱 아이콘을 선택합니다.
2. 목록이 비어 있으면 **추가 요청 복사**를 누릅니다. 앱 이름·번들 ID·버전과 설치 방법이 복사됩니다.
3. 로컬 파일과 명령 실행을 지원하는 코딩 에이전트에 붙여 넣습니다. 자동 전송은 없으며 Cheatble 자체에는 외부 서비스 계정이나 API 키가 필요하지 않습니다.
4. 공식 macOS 문서 또는 실제 앱 메뉴를 확인해 JSON 팩을 만들고, 아래 CLI로 설치하도록 요청합니다.
5. 저장된 앱 드롭다운에서 새 목록을 선택합니다. 팩 변경은 2초 주기로 확인하며 재시작할 필요가 없습니다.

이미 단축키가 있는 앱이나 웹사이트·도구 목록을 추가할 때는 다음 요청문의 값을 바꿔 사용하세요.

```text
Cheatble에 <앱 또는 도구 이름> 단축키를 추가해줘.
대상 버전: <버전>, macOS 앱 번들 ID 또는 목록 ID: <ID>.
공식 macOS 문서나 실제 앱 메뉴에서 확인한 조합만 사용해줘.
확인되지 않은 키는 추측하지 말고, 동작 이름과 카테고리는 한국어로 작성해줘.
공식 출처는 sourceURL에, 적용 조건은 detail에 넣어줘.
아래 명령으로 JSON 형식을 확인해줘.
/Applications/Cheatble.app/Contents/MacOS/Cheatble --pack-example
기존 팩을 갱신한다면 동작 ID를 유지하고 계속 사용할 기존 항목도 포함해줘.
완성된 JSON은 --install-pack <JSON 절대 경로>로 설치해줘.
library.json과 내가 직접 수정한 항목은 변경하지 마.
설치 파일 경로, 단축키 개수, 확인한 출처를 알려줘.
```

### 직접 추가하거나 JSON 팩 가져오기

몇 개만 추가하려면 **설정 → 앱별 단축키 설정 → 단축키 추가…**를 사용하세요. 전체 목록은 설정의 **추가 목록 가져오기** 또는 다음 명령으로 설치합니다.

```sh
# 형식 예시 출력: 예시 값은 확인한 실제 단축키로 교체하세요.
/Applications/Cheatble.app/Contents/MacOS/Cheatble --pack-example

# 완성한 파일 검증 및 설치
/Applications/Cheatble.app/Contents/MacOS/Cheatble --install-pack "/absolute/path/app-shortcuts.json"
```

팩에는 `schemaVersion: 1`, `bundleIdentifier`, `appName`, `shortcuts` 배열이 필요합니다. 각 항목의 필수 값은 `id`, `title`, `category`, `keys`이며 선택 값은 `detail`, `aliases`, `sourceURL`입니다. [전체 JSON 예시](docs/app-packs.md#팩-형식과-설치)와 [내장 팩](Sources/CheatbleCore/Resources/Packs)을 참고하세요.

설치 위치는 `~/Library/Application Support/Cheatble/Packs/<bundleIdentifier>.json`입니다. 잘못된 파일은 기존 팩을 덮어쓰지 않습니다. 설치 팩은 같은 ID의 내장 팩 전체를 대체하므로 유지할 항목도 모두 포함하세요. 직접 수정한 사용자 값이 팩보다 우선하며 동작 ID를 유지해야 즐겨찾기·공부 완료·수정 값이 이어집니다. 팩과 사용자 목록 내보내기 JSON은 서로 다른 형식입니다.

## 소스 빌드

Xcode Command Line Tools와 Swift 6 이상이 필요합니다. 전체 Xcode나 유료 Apple 개발자 계정은 필요하지 않습니다.

```sh
python3 scripts/setup-signing.py   # 로컬 서명 키 최초 설정
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/smoke-test.sh        # 로그인한 macOS GUI 환경 필요
```

빌드한 Mac의 CPU에 맞는 `dist/Cheatble.app`과 `dist/Cheatble.zip`을 만듭니다. 임시 디렉터리에서 패키징·검증을 마친 뒤 기존 결과물을 교체하며 교체 오류가 나면 이전 결과물로 복구합니다. `CHEATBLE_CACHE_DIR`로 빌드 캐시 경로를 지정할 수 있습니다.

서명 키는 로그인 키체인에 보관됩니다. macOS가 요청하면 `codesign`의 키 사용을 허용하세요. 공개 서명 설정은 저장소 밖의 `~/Library/Application Support/Cheatble/Signing`에 보관됩니다. 업데이트 시 같은 키를 사용해야 손쉬운 사용 권한을 유지할 수 있습니다. 임시 테스트용으로 `CHEATBLE_ADHOC_SIGNING=1 bash scripts/build-app.sh`를 사용할 수 있으나 이를 인증서 서명 설치본에 덮어쓰면 앱의 서명 식별이 바뀝니다.

`python3 scripts/verify-signing.py`는 업데이트 식별 유지, 같은 앱 ID를 가진 다른 서명 거부, 리소스 변조 탐지를 검사합니다. 임시 복사본에 서명하므로 키체인 확인이 나타날 수 있습니다. 스모크 테스트는 별도 앱 ID·임시 데이터·테스트 단축키를 사용합니다. 여러 모니터·Spaces·앱별 동작은 [수동 확인 목록](docs/manual-validation.md)을 참고하세요.

## 데이터와 문제 해결

| 데이터 | 위치 |
| --- | --- |
| 사용자 항목·저장한 메뉴·즐겨찾기·공부 완료 | `~/Library/Application Support/Cheatble/library.json` |
| 설치한 단축키 팩 | `~/Library/Application Support/Cheatble/Packs/` |
| 복사한 추가 요청 | `~/Library/Application Support/Cheatble/Requests/` |
| 창·전역 단축키 설정 | UserDefaults 도메인 `app.cheatble.desktop` |

- **권한을 허용했는데 안내가 보이는 경우:** 손쉬운 사용의 허용 항목이 `/Applications/Cheatble.app`인지 확인하세요. 소스 폴더에서 `python3 scripts/permission-status.py`를 실행하면 LaunchServices로 GUI 앱 권한을 진단합니다. 실행 파일을 터미널에서 직접 실행하면 터미널의 권한 문맥이 반영될 수 있습니다.
- **앱 메뉴 단축키가 적거나 없는 경우:** 앱을 활성화하고 새로 고치거나 **메뉴 더 읽기**를 사용하세요. 모든 앱이 전체 단축키를 손쉬운 사용 API로 제공하지는 않으므로 팩으로 보완할 수 있습니다.
- **팩을 갱신해도 수정한 값이 보이는 경우:** 직접 수정한 값이 우선입니다. 앱별 단축키 설정에서 해당 수정 값을 제거하면 팩이나 메뉴 값이 나타납니다.
- **저장한 목록을 읽지 못하는 경우:** 원본을 보존하고 쓰기를 중지합니다. 설정의 복구 기능은 원본 파일을 백업한 후 새 목록을 시작합니다.

Cheatble은 키 입력·브라우저 기록·사용 정보를 수집하거나 표시된 단축키를 대신 실행하지 않습니다. 앱 메뉴 읽기에는 사용자가 허용한 손쉬운 사용 권한만 사용합니다.
