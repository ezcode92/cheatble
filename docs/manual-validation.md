# 실제 macOS 확인 항목

자동 테스트로 확인할 수 없는 OS·앱별 동작입니다. 아래 항목은 실제로 확인하기 전에는 완료로 표시하지 않습니다.

- [ ] 권한 거부 상태: macOS 68개와 내장 앱·도구·웹 목록 9개 표시. 권한 안내 중에도 검색·즐겨찾기 가능.
- [ ] 권한 허용/회수: 2초 이내 상태 반영, 회수 시 이전 메뉴 캐시 제거. 권한 프롬프트 반복 없음.
- [ ] Finder → Safari → Terminal 전환: 현재 앱 아이콘·메뉴·설명 갱신. 앱 자체 설정 창은 대상 앱으로 오인하지 않음.
- [ ] 상단 선택 영역은 현재 앱·사과·저장된 앱 선택 세 개. ∨ 드롭다운의 아이콘 격자에서 선택·검색·스크롤 가능하며 현재 활성 앱은 중복 표시하지 않음.
- [ ] 사과 또는 저장된 앱 선택 후 앱 전환: 목록·검색·필터 유지, 첫 아이콘만 변경. 저장된 앱이 활성화되어도 자동 전환 모드로 바뀌지 않음.
- [ ] 메뉴 읽기: 비활성 항목 구분, 사용자 수정 우선, 빠르게 앱 전환해도 이전 결과가 새 목록을 덮지 않음.
- [ ] 추가 메뉴 읽기: 사용자 선택 후에만 메뉴 열림. 명령 실행 없음. 취소/앱 전환 후 열린 메뉴 정리.
- [ ] Safari·Electron 앱의 지연 생성 메뉴: 일부 수집 상태가 정확하게 표시됨.
- [ ] 시트의 탭·즐겨찾기·필터·행·불투명도 클릭 중 원래 앱 활성 상태 유지.
- [ ] 카테고리 헤더 전체(제목·개수·빈 공간·화살표)가 높이 26pt의 클릭 영역이며 어디를 눌러도 펼치기·접기가 동작함.
- [ ] 검색창 클릭 후 입력 가능, Enter 및 Escape 두 번으로 원래 앱에 입력 복귀.
- [ ] 편집기: 복사·붙여넣기, 새 단축키·수정·되돌리기, 잘못된 키 조합 오류.
- [ ] 모니터 두 대: 같은 앱의 다른 창 선택, 활성 창 이동, 화면 연결/해제 시 시트가 화면 밖으로 나가지 않음.
- [ ] 전체 화면 및 Spaces 전환: 시트 표시와 대상 앱 추적. 시스템이 제한하는 화면에서는 동작 차이 기록.
- [ ] 왼쪽 아래 사선 손잡이, 왼쪽·아래 가장자리에서 첫 클릭부터 드래그로 크기 조절: 오른쪽 위 기준 유지. 재시작 후 크기·불투명도·탭 복원.
- [ ] 불투명도 20%에서 배경·글자·아이콘이 함께 투명해지고 100%에서 복원됨. 밝은/어두운 모드, 최소 크기에서 조작 가능.
- [ ] 각 키캡의 영역은 유지되고 내부 기호·글자가 커짐. Space, Fn, esc 등 여러 글자도 넘치지 않음.
- [ ] tmux의 prefix와 다음 키가 `⌃ B → 다음 키` 순서로 한 줄에 표시됨. 최소 너비와 단축키 편집 미리 보기에서도 키 순서와 개별 키캡 유지.
- [ ] JSON 가져오기·내보내기, 파일 접근 실패, 손상 파일 복구 시 원본 백업 확인.
- [ ] 실제 키보드에서 Control+Option+Command+Return를 눌러 시트 숨기기·다시 열기. 설정에서 변경·해제 후 적용 확인.
- [ ] 단축키가 없는 앱의 “추가 요청 복사”를 눌러 다른 편집기에 붙여 넣으면 앱 이름·ID·버전이 정확함.
- [ ] 팩 가져오기 후 2초 이내 아이콘 목록 갱신. 재시작 없이 새 키 표시. 사용자 수정은 우선 유지.
- [ ] Google 검색은 Safari용 목록이며 Chrome 키가 섞이지 않음. tmux는 prefix를 놓고 다음 키를 누름. cmux 사용자 키 설정과 비교.
- [ ] 응용 프로그램 폴더와 Dock에서 새 키보드·참조 시트 아이콘 표시.

- [ ] 선택된 앱 이름이 아이콘 선택 영역 오른쪽에 표시되고 아래 제목·설명 줄이 없음. 하단은 불투명도만, 접힌 단축키 행에는 관리 버튼이 없고 펼친 상세 영역에 즐겨찾기·공부 완료·연필 버튼이 있음.
- [ ] 앱별 단축키 설정에서 다른 앱을 선택해 추가·수정·즐겨찾기·익힘·사용자 값 제거: 오버레이의 선택 앱은 유지됨.
- [ ] 실제 키보드로 ⌃⌥⌘J, K, ; 실행: 현재 앱·macOS·저장된 앱 선택이 각각 독립적으로 동작하며 작업 앱 활성 상태를 유지함.
- [ ] 저장된 앱 선택 단축키를 다시 누르면 닫힘. 열면 검색 입력에 포커스가 있고 방향키로 이동, Return 선택, Esc 닫기가 동작함. 닫으면 작업 앱에 키보드 포커스가 돌아감.
- [ ] 상단 CHEATBLE 영역을 첫 클릭부터 드래그해 이동. 다른 앱 전환과 시트 숨기기·보이기, 재시작 후 위치 유지. 모니터 제거 시 화면 안으로 복귀.
- [ ] 창 너비를 240pt까지 축소 가능. 596pt에서 2단, 888pt에서 3단으로 전환. 2단 이상일 때 각 단은 최소 280pt이며 축소 시 키가 잘리지 않음. 카테고리 전체 줄 클릭은 유지.
- [ ] Excel 40개, Word 36개, PowerPoint 40개를 앱이 꺼져 있어도 선택할 수 있고 각 앱 활성화 시 해당 목록 표시.
- [ ] 밝은 모드·어두운 모드에서 회색 선택 색상, SF Symbols와 글자 대비 확인. 앱 상단·설정·Dock에 동일한 회색 앱 아이콘 표시.
- [ ] `/Applications/Cheatble.app`에 손쉬운 사용 권한을 부여한 뒤 `python3 scripts/permission-status.py`가 trusted: true이며 현재 앱 탭의 권한 안내가 사라짐. 터미널에서 바이너리를 직접 실행한 결과를 GUI 앱의 권한으로 해석하지 않음.
- [ ] 후속 업데이트도 같은 인증서 지문과 앱 ID로 서명. 이전 릴리스의 designated requirement를 통과하고 권한 유지. 테스트 앱 ID는 `app.cheatble.smoke`이며 설치본과 구분됨.
